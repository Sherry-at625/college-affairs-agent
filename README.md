# 学院事务咨询助手

依据 5 份**现行有效**学院制度文件作答的条款级问答智能体，回答**补考、缓考、重修、成绩复核、奖助学金、宿舍与教室报修**六大类事务。

每条回答固定三段：**【结论】【依据】【下一步】**，并在【依据】中给出**文件名 + 条款号 + 原文关键句**，可回原文逐字核对；资料中查不到时原样输出兜底话术，不推测、不编造。

## 在线使用

打开 GitHub Pages 链接即可，手机优先，无需登录。

## 设计要点

- **条款级检索**：5 份文件切成 58 条条款片段，35 条意图映射，旧版文件（教室多媒体报修流程 2023 版）已归档、不在检索范围
- **语料已脱敏**：原始咨询记录（含姓名／学号／手机号）未入库，仅保留脱敏后的"问题类型 + 次数 + 条款"
- **取值优先级**：正式文件 > FAQ；新版 > 旧版；不同适用对象（宿舍 / 教室）的条款不合并
- **边界前置**：医疗、投资、处分个案、代写代办、业务无关五类请求一律不越界作答
- **零依赖单页**：无后端、无外部请求，`index.html` + `engine.js` + `kb.json` 即可运行

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单页问答界面（移动端优先） |
| `engine.js` | 检索与作答引擎 |
| `kb.json` | 知识库（条款片段 + 意图映射 + 边界规则） |
| `kb.data.js` | 与 kb.json 同源的副本，供 file:// 直接打开 |
| `使用说明.md` | 适用范围、不适用范围、语料更新与回归测试步骤 |
